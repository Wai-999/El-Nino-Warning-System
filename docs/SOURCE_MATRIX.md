# Source integration matrix

Checked 31 October 2026. Runtime canonical reference: `#/sources`. Machine-readable registry: `src/data/indicators.json`, exported as `data/indicator-registry.json` and through the Sources download.

| Product                      | Class                              | Precision and period                                                                            | Source / terms                                                                                                                        | Cadence and fallback                                                                                |
| ---------------------------- | ---------------------------------- | ----------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| Regional weather             | Model forecast                     | Three IFS 0.25° cells per region; latest model hour, next24 summary, seven daily periods in MMT | [ECMWF / Open-Meteo](https://open-meteo.com/en/docs/ecmwf-api), CC BY 4.0 / noncommercial API                                         | Four scheduled checks daily; 18-hour freshness, original model/retrieval times retained on failure. |
| Historical weather/anomalies | Reanalysis / derived               | Same ERA5 0.25° samples, 30 completed days; matched 1991–2020 calendar normals                  | [Copernicus / Open-Meteo](https://open-meteo.com/en/docs/historical-weather-api), CC BY 4.0                                           | Daily, approximately six-day lag; stale once final day is ten days old. No incompatible backup.     |
| Heat index                   | Derived                            | Shaded/light-wind estimate from model temperature/RH; extrema across samples and forecast hours | [NWS equation](https://www.wpc.ncep.noaa.gov/html/heatindex_equation.shtml)                                                           | Inherits weather dates; not official or medically personalized.                                     |
| ENSO assessment              | Official Pacific assessment        | Source issue date and stated next discussion; no exact issue clock asserted                     | [NOAA discussion](https://www.cpc.ncep.noaa.gov/products/analysis_monitoring/enso_advisory/ensodisc.shtml), US government information | Monthly, checked on schedule; expired assessment marked historical.                                 |
| RONI                         | Derived published index            | Three-month ERSSTv6 relative Niño 3.4; 1991–2020; full 1950+ history retained                   | [NOAA raw data](https://www.cpc.ncep.noaa.gov/data/indices/RONI.ascii.txt), attribution                                               | Monthly; newest values provisional. Validity checks both latest completed season and retrieval age. |
| ENSO phase outlook           | Official probabilistic outlook     | Nine overlapping three-month periods; issue month only                                          | [NOAA probabilities](https://www.cpc.ncep.noaa.gov/products/analysis_monitoring/enso/roni/probabilities/), attribution                | Monthly; 62-day policy from issue-month start. No invented day/time or confidence.                  |
| ENSO strength statement      | Source-parsed assessment statement | Distinct event-strength range and during/through period, if present                             | Same NOAA discussion                                                                                                                  | Inherits original assessment dates; never substituted for phase probabilities.                      |
| Monthly Niño 3.4             | Published SST anomaly              | Completed months; separate from RONI/ONI; baseline not asserted in app                          | [NOAA sstoi.indices](https://www.cpc.ncep.noaa.gov/data/indices/sstoi.indices)                                                        | Daily check at most; retained last good period with explicit source.                                |
| Myanmar official warnings    | Unconnected official issuer        | Only explicit issuer geography/time/severity may be used                                        | [DMH](https://www.moezala.gov.mm/en); links only, redistribution terms unverified                                                     | No automated active coverage. No notice is not an all-clear.                                        |
| Regional boundaries          | Reference geometry                 | Simplified 2024 admin1, 15 regions                                                              | [MIMU/OCHA/HDX](https://data.humdata.org/dataset/cod-ab-mmr), CC BY 3.0 IGO                                                           | Manual updates; no township/village measurement claim.                                              |
| Preparedness / health        | Static education                   | General, hazard-specific; no weather-triggered diagnosis/disease estimate                       | WHO, NWS; exact links in runtime registry and `DESIGN_RESEARCH.md`                                                                    | Editorial review target every 90 days; brief paraphrases, not copied graphics.                      |
| Agriculture                  | Static general guidance            | Rice/maize/pulses and explicit user-selected crop stage; field conditions unknown               | FAO GIEWS/crop-water guidance                                                                                                         | Seasonal editorial review; no precise planting date or yield promise.                               |

Unshipped indicators have individual reasons in the registry: full hourly arrays, rain probability, calibrated heatwaves/warm nights, wet bulb, wind direction/pressure, rainfall percentiles/monthly/seasonal anomalies, gauge levels/discharge, verified flood extent, township/village search, SPI/SPEI, soil moisture, evapotranspiration, vegetation stress, local seasonal/subseasonal outlooks, advanced ENSO indices, UV/air quality and push/Telegram delivery. Trusted external products are linked where appropriate, with their own true scope.

No provider is silently averaged with or substituted for an incompatible dataset. Observations, forecasts, reanalysis, derived indices, issued notices and educational guidance remain distinct.
