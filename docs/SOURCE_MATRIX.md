# Source integration matrix

Updated 1 November 2026. Runtime canonical reference: `#/sources`. Machine-readable registry: `src/data/indicators.json`, exported as `data/indicator-registry.json` and through the Sources download.

| Product                      | Class                              | Precision and period                                                                            | Source / terms                                                                                                                        | Cadence and fallback                                                                                |
| ---------------------------- | ---------------------------------- | ----------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| Regional weather             | Model forecast                     | Three IFS 0.25° cells per region; latest model hour, next24 summary, seven daily periods in MMT | [ECMWF / Open-Meteo](https://open-meteo.com/en/docs/ecmwf-api), CC BY 4.0 / noncommercial API                                         | Four scheduled checks daily; 18-hour freshness, original model/retrieval times retained on failure. |
| Historical weather/anomalies | Reanalysis / derived               | Same ERA5 0.25° samples, 30 completed days; matched 1991–2020 calendar normals                  | [Copernicus / Open-Meteo](https://open-meteo.com/en/docs/historical-weather-api), CC BY 4.0                                           | Daily, approximately six-day lag; stale once final day is ten days old. No incompatible backup.     |
| Heat index                   | Derived                            | Shaded/light-wind estimate from model temperature/RH; extrema across samples and forecast hours | [NWS equation](https://www.wpc.ncep.noaa.gov/html/heatindex_equation.shtml)                                                           | Inherits weather dates; not official or medically personalized.                                     |
| ENSO assessment              | Official Pacific assessment        | Source issue date and stated next discussion; no exact issue clock asserted                     | [NOAA discussion](https://www.cpc.ncep.noaa.gov/products/analysis_monitoring/enso_advisory/ensodisc.shtml), US government information | Monthly, checked on schedule; expired assessment marked historical.                                 |
| RONI                         | Derived published index            | Three-month ERSSTv6 relative Niño 3.4; 1991–2020; full 1950+ history retained                   | [NOAA raw data](https://www.cpc.ncep.noaa.gov/data/indices/RONI.ascii.txt), attribution                                               | Monthly; newest values provisional. Validity checks both latest completed season and retrieval age. |
| ENSO phase outlook           | Official probabilistic outlook     | Nine overlapping three-month periods; issue month only                                          | [NOAA probabilities](https://www.cpc.ncep.noaa.gov/products/analysis_monitoring/enso/roni/probabilities/), attribution                | Monthly; 62-day policy from issue-month start. No invented day/time or confidence.                  |
| ENSO strength statement      | Source-parsed assessment statement | Distinct event-strength range and during/through period, if present                             | Same NOAA discussion                                                                                                                  | Inherits original assessment dates; never substituted for phase probabilities.                      |
| Monthly Niño 3.4             | Published SST anomaly              | Completed months; separate from RONI/ONI; baseline not asserted in app                          | [NOAA sstoi.indices](https://www.cpc.ncep.noaa.gov/data/indices/sstoi.indices)                                                        | Daily check at most; retained last good period with explicit source.                                |
| Myanmar official warnings    | Unconnected official issuer        | Only explicit issuer geography/time/severity may be used                                        | [DMH](https://www.moezala.gov.mm/en); links only, redistribution terms unverified                                                     | No automated active coverage. No notice is not an all-clear.                                        |
| Regional boundaries          | Reference geometry                 | Simplified 2024 admin1, 15 regions                                                              | [MIMU/OCHA/HDX](https://data.humdata.org/dataset/cod-ab-mmr), CC BY 3.0 IGO                                                           | Manual updates; no township/village measurement claim.                                              |
| Preparedness                 | Static education                   | General hazard-specific preparedness; no clinical-health panel                                  | WHO, NWS; exact links in runtime registry and `DESIGN_RESEARCH.md`                                                                    | Editorial review target every 90 days; brief paraphrases, not copied graphics.                      |
| Agriculture                  | Static general guidance            | Rice/maize/pulses and explicit user-selected crop stage; field conditions unknown               | FAO GIEWS/crop-water guidance                                                                                                         | Seasonal editorial review; no precise planting date or yield promise.                               |

Unshipped products retain individual reasons in the registry: calibrated heatwaves/warm nights, rainfall percentiles/calendar-month/seasonal anomalies, gauge levels/discharge, verified flood extent, complete village search, direct township warnings, SPI/SPEI, soil-moisture anomalies, actual crop evapotranspiration, vegetation stress, calibrated local long outlooks, standalone trade-wind/subsurface indicators, UV/air quality and push/Telegram delivery. Availability of upstream data is not equivalent to a scientifically validated production integration. See [the explicit acceptance and remaining-gate audit](SPEC_COMPLETION_AUDIT.md).

No provider is silently averaged with or substituted for an incompatible dataset. Observations, forecasts, reanalysis, derived indices, issued notices and educational guidance remain distinct.

## V3.1 source additions

- Township names/hierarchy: pinned MIMU-derived OCHA/HDX v01, valid 2024-02-15; review 2025-10-30; resource upload 2026-08-14. 330 complete bilingual townships, 80 districts and 18 source admin1 units; CC BY 3.0 IGO with extraction/crosswalk disclosure. Nine reviewed GeoNames aliases are separately attributed CC BY 4.0. Partial village records excluded. [Maintenance and exact download/checksum](GEOGRAPHY_MAINTENANCE.md).
- WHO Disease Outbreak News: exact Myanmar-country-tagged JSON metadata, one bounded request per scheduled run. Original issue field differs from CMS migration/modified date. No expiry, severity or local applicability supplied; current health-advisory coverage remains unknown. Metadata/direct links under WHO linking policy; no full clinical text, branding, endorsement or unreviewed translation.
- Emergency contacts: [ICRC Myanmar FAQ](https://www.icrc.org/en/article/FAQ-icrc-work-myanmar), published 2026-06-30, and [MRCS EOC](https://www.redcross.org.mm/our-work/emergency-operations-center/), checked 2026-10-31. Ambulance scope is some locations; EOC availability is during emergency activation. No universal dispatch guarantee or test calls.

## V3.2 verified additions

- **City/town names:** separate GeoNames CC BY 4.0 settlement points, original record dates and language-tagged labels. 515-point bounded extract, 337 source Burmese labels, original English fallback. Twelve individually checked alternate/historical names; no arbitrary alias import. Typed IDs and unique derived containment in 2024 HDX township polygons, with upstream parent-code discrepancies retained. Exact source/geometry checksums in `settlements.json`; reproducible standard-library importer `scripts/build-settlements.py`. MIMU’s separately licensed TownPoint product was excluded because web embedding requires prior written agreement.
- **Hourly grid detail:** the existing forecast request now retains all 168 hours at the 45 exact returned sample cells, plus point ensemble rain probability, direction/pressure, provider-derived wet-bulb, modeled moisture at 0–7 and 7–28 cm and reference FAO ET₀. The model’s run issue clock is unknown; valid/reference/retrieval times are distinct. No regional probability or ordinary mean of wind angles is fabricated. First-use download/cache, not Home prefetch. Fifteen variables cost about 67.5 weighted calls per refresh; a bounded rejected-variable retry uses the core seven fields. Existing baseline budget remains intact.
- **Advanced Pacific indices:** independent official ONI v6 HTML table, CPC standardized SOI block and NOAA PSL MEI.v2 text. Full published histories, source periods, version/method disclosures and independent dated fallback; no common baseline or conversion to local warnings. Real upstream fixtures cover the malformed final ONI row, both SOI blocks and the MEI cross-year bimonthly period. `enso-indices.json` is an optional first-use cached source snapshot.
