# Production source registry

Verified against provider documentation and actual responses on 30 September 2026. This public-interest application is noncommercial and has no advertisements or subscriptions. All ingestion occurs in Node/GitHub Actions; browser CORS for third-party feeds is immaterial because clients fetch same-origin validated JSON. No API credentials are needed or shipped.

Sector context also uses [WHO drinking-water guidance](https://www.who.int/news-room/fact-sheets/detail/drinking-water), [FAO El Niño](https://www.fao.org/el-nino/en/) and [WMO energy](https://wmo.int/themes/energy). These are general qualitative references, not operational measurement feeds; resolution/horizon/rate limits do not apply, content is linked and briefly paraphrased, and no full articles are redistributed.

## Evaluated but not ingested

[CHIRPS](https://www.chc.ucsb.edu/data/chirps) offers an independent rainfall product, but mixing its rainfall with an ERA5 baseline would be scientifically incompatible. A separate CHIRPS historical pipeline would be required. ERA5 is used consistently for V2. Soil moisture, vegetation, river/reservoir levels, disease, crop loss, grid outages and probabilistic rain forecasts are not inferred from missing feeds.

FAO/[GEOGLAM Crop Monitor](https://www.cropmonitor.org/)/NASA guidance and products were considered for future land monitoring; V2 agriculture signals are explicitly weather-based planning proxies, not satellite crop assessments. DMH remains a prominent official-source link; no reliable machine-readable warning feed was verified. WMO, ReliefWeb/OCHA, GDACS and AHA Centre remain candidate warning/update providers; none is treated as complete Myanmar official-warning coverage. The current automatically curated updates feed is limited to validated NOAA publications. It is labeled global ENSO context, not a Myanmar emergency-news service.

## Provenance and use constraints

Forecasts and reanalysis use `elevation=nan`, `cell_selection=nearest`, consistent coordinates and Asia/Yangon days. Grid snapping is recorded and validated. The boundary aggregation and three-cell stratified sampling are modified/derived products. Public values are rounded to useful precision; the calculation preserves unrounded intermediate values. Original source links accompany each dataset. Provider failure never changes valid time. A future commercial operator must obtain an appropriate Open-Meteo plan before using the free endpoint commercially. See [Open-Meteo terms](https://open-meteo.com/en/terms) and [weighted-call pricing documentation](https://open-meteo.com/en/pricing).
