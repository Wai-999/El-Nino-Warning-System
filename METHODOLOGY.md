# Methodology

The maintained [methodology](docs/METHODOLOGY.md) describes coverage, freshness, canonical IDs, official-warning precedence, snapshot comparison and historical evidence. Existing [numeric threshold rules](docs/RISK_METHODOLOGY.md) remain documented separately. Missing data is never low risk; regional context is never a Myanmar official warning.

Version 2.2 adds [health and triage rules](HEALTH_GUIDANCE_METHODOLOGY.md), country-first location selection, explicit regional min/max summaries, inspectable KPI contracts and separately dated qualitative surveillance. The [content ownership audit](CONTENT_AND_FEATURE_AUDIT.md) and [research gaps](DATA_GAPS.md) explain the UI and integration decisions.
