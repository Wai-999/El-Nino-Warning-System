# Impacts audit — 1 October 2026

Baseline: commit `1c4cb82`, V2 production at <https://wai-999.github.io/El-Nino-Warning-System/?release=2.0.0#/impacts>. Audit completed before application edits. Findings below distinguish observed production behavior from deliberate fault-injection tests.

## Architecture and scope

React 19 + TypeScript; custom hash navigation in `src/app/App.tsx`; Vite 7 with `/El-Nino-Warning-System/` base. Impacts is a lazy route, with no map, WebGL or 3D engine. The separate map uses d3-geo with MIMU-derived GeoJSON. Data are same-origin validated snapshots: NOAA `current.json`, and ECMWF IFS / ERA5 / NOAA Niño 3.4 in `operational.json`. GitHub Actions refreshes data and deploys the tested `dist` directory to Pages. Reviewed the repository architecture, ingestion, schemas, risk rules, shared components, styling, offline builder, tests, source documentation and deployment configuration.

## Checks that passed before repair

- Root, `/#/impacts`, `/?release=2.0.0#/impacts` and direct refresh loaded on local and public builds; correct Pages base path. No reason to replace routing architecture.
- Both languages: 320×568, 375×667, 390×844, 430×932, 768×1024: no horizontal overflow; no automated axe WCAG A/AA violations. No confirmed clipped or overlapping text. These are regression constraints, not fabricated mobile/accessibility bugs.
- No page errors, React warnings, failed requests or HTTP 4xx/5xx in ordinary browsing. “Service Worker registration blocked by Playwright” is an explicit audit harness warning, not a production defect. A separate service-worker-enabled recheck is required after repair.
- Current page makes no fabricated crop-loss/disease probabilities; actual damage and official warnings are already distinguished. Preserve that language.
- Production impacts refresh downloaded 218,466 encoded resource bytes in the measured browser run (including two Myanmar fonts; cache-dependent). Impacts chunk 3,701 bytes; main JS 102,588; CSS 8,308. No GeoJSON, WebGL or 3D library request on this route. No proven heavy-rendering defect to fix.
- Weather and historical datasets each cover 15 unique regions. Dates, models and 1991–2020 baseline exist, but much provenance is behind disclosure. Rain is mm, anomaly percentage uses normal rainfall, and no flood probability is calculated.

## Limitations and completion evidence

No authoritative Myanmar warning feed, station observations, crop exposure/stage, reservoir/river levels, disease surveillance or fire/air-quality feed is connected. Three regional sample cells are not township-level evidence. Human Burmese terminology and assistive-technology review remain desirable; automated accessibility does not establish full WCAG conformance.
